# scripts

The Main Tracker's scripts. Like the core's `ledger.py`, which `proposals.py` imports from
`../../zynkr-ops-weekly/scripts/` (`ZYNKR_OPS_WEEKLY_SCRIPTS` overrides; it refuses a core of another
`API`), they work from files in a run folder and print every MCP call for the model to make exactly.

| Script | In → Out |
|---|---|
| `notes_append.py` | The one raw Sheets API write (`SKB-091`, decision A): appends one dated line to one 備註 cell and keeps the cell's links, which a values write deletes. Runs a job `proposals.py live-plan` wrote, only in the apply beat; refuses a cell that changed since the plan, a formula, a number or an emoji, and reads the cell back. Token from `routine.sheets_credentials`. `--selftest`, `--mutate` |
| `proposals.py` | The Friday close-out (`SKB-044` Phase 3, `SKB-091`): `propose` reads the tracker and the week's Ledger evidence, `check` refuses any change outside `../references/proposal-rules.md` (新增 and 放棄 included) and renders the 【週結】 mail, the week's summary first, `sent` guards the one send (`--send-failed` frees it after an error) and checks the mail in Sent is word for word the checked one; `apply-*` reads the owner's reply in that thread (`全部核准` · `核准 1 3` · `退回 2`; strict on purpose: an approving reply that asks or says more than thanks is unreadable), waits while a draft is open, asks once to restate a reply it cannot read, writes the decision to the `Proposals` block, reads that block and the thread again, confirms in the thread, and only then writes the `Updates` block that marks the week applied. In live mode `live-pages`, `live-plan` and `live-check` write the approved cells in between: each re-read first, a hand-edited one skipped, 新增 rows appended, 備註 through `notes_append.py`, every cell read back. `--selftest`, `--mutate` |
| `tracker_guard.py` | The runner's PreToolUse hook (`SKB-044` AC-3.5), not run by the model: refuses any call aimed at the Main Tracker unless it only reads or the beat is `apply` writing values (or appending rows, or running `notes_append.py` in its one shape), and any call that reaches into the owner's weekly-insights folder, reads included. Exit 2 refuses; an error inside it refuses every call but a read. `project-manager`'s runner reads it from here. `--selftest`, `--mutate` |
